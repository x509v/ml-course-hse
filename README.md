# Learning ML with the HSE Machine Learning Course

This is my personal repository for learning machine learning on my own. I'm working through the materials of the **Machine Learning** course taught in the Applied Mathematics and Computer Science bachelor's program at the HSE Faculty of Computer Science.

All lecture notes, seminars and homework assignments come from the original course: [esokolov/ml-course-hse](https://github.com/esokolov/ml-course-hse). This repo holds my notes and my solutions to the assignments.

## Structure

| Folder | Contents |
| --- | --- |
| [`ml_part1`](ml_part1) | Part 1: linear models, gradient descent, classification, trees, boosting |
| [`ml_part1/lecture-notes`](ml_part1/lecture-notes) | Lecture notes |
| [`ml_part1/seminars`](ml_part1/seminars) | Seminar notebooks |
| [`ml_part1/homework-practice`](ml_part1/homework-practice) | Practical homework (my solutions) |
| [`ml_part1/homework-theory`](ml_part1/homework-theory) | Theory homework |
| [`ml_part2`](ml_part2) | Part 2: kernels, EM, anomaly detection, clustering, kNN, recommender systems |
